## **1. script 태그**
### 1-1. 특징
- `<script>` 태그는 브라우저에게 **“여기 자바스크립트 코드가 있다!”** 라고 알려주는 태그이다.  
- `src="main.js"` 속성을 사용하면 **외부 자바스크립트 파일을 불러올 수 있다.**


### 1-2. 외부 스크립트 사용 이유
- **코드가 깔끔하다.** → HTML과 JS를 분리하여 보기 쉽다.  
- **재사용이 가능하다.** → 같은 스크립트를 여러 페이지에서 사용할 수 있다.  
- **유지보수가 편하다.** → HTML을 수정하지 않고 JS만 수정해도 된다.  
- **로딩 속도가 향상된다.** → 브라우저 캐시에 저장되어 빠르게 실행된다.

### 1-3. 언제 쓸까?
- 코드가 짧고 한 페이지만 사용할 때는 **HTML 안에 `<script>`를 직접 작성하는 것이 좋다.**  
- 코드가 많거나 여러 페이지에서 재사용할 때는 **외부 파일로 분리하는 것이 효율적이다.**


```html
<!-- HTML 안에서 직접 자바스크립트 코드 작성 -->
<script>
  console.log("자바스크립트 실행 중!");
</script>

<!-- 외부 파일을 연결할 때 -->
<script src="main.js"></script>
```

##  **2. 코드 구조 (Statement)**

- 코드문은 명령, 세미콜론은 구분, 주석은 설명!

```javascript

// 코드문 (statement)
let name = "jerry";   

// 세미콜론 (;)
console.log(name);   

// 주석 (Comment)
// 사람을 위한 설명, 컴퓨터는 무시함
```

## 3. **엄격 모드 (Use Strict)**
- `'use strict'`는 자바스크립트를 **더 안전하고 정확하게 실행하도록 만드는 지시문**이다.  
- 한 줄로 스크립트 전체에 적용되며, **항상 코드의 맨 위에 작성해야 한다.**  
- 함수 내부에 작성하면 **해당 함수에만 적용된다.**  
- 한 번 활성화하면 **다시 끌 수 없다.**

```javascript
'use strict';
x = 10; // ❌ 오류! 변수 선언 안 함
let y = 10; // ✔️ 올바른 선언
```

## 4.  **변수 (Variable)**
### 4-1. 특징
- 데이터를 저장하는 이름 붙은 상자
- 값 변경 가능

### 4-2. 규칙
    - `문자, 숫자, _, $`만 사용가능
    - 숫자로 시작 불가
    - 대소문자 구분
    - 예약어 사용금지 (`let, return, class`)

```javascript
let name = "jerry";   // 변수 선언
name = "bango";       // 값 변경 가능

let age = 20;
let user_name = "poby"; // _ 사용 가능
let $price = 1000;       // $ 사용 가능
```

## 5. **상수 (Constant)**
- 한 번 정하면 바꿀 수 없는 값 (고정값)
- 대문자 상수는 변하지 않는 설정값 (API, 색상 등)에 사용
- 이름은 의미 있고 읽기 쉽게 camelCase 권장

```javascript
const PI = 3.14; // 대문자 상수 (변하지 않는 값)
const apiUrl = "https://api.example.com"; // 의미 있는 이름
const mainColor = "#FF6600"; // 색상 코드

const PI = 3.14159;  // ❌ 오류! const는 값 변경 불가
```

## 6. **자료형 (Data Types)**
### 6-1. 특징
- 값의 형태를 **자료형(Data Type)** 이라고 한다.  
- 같은 변수에 어떤 값이든 저장할 수 있으며, **언제든 자료형이 바뀔 수 있다.**  
- 자바스크립트는 **유연한 동적 타입 언어(Dynamically Typed Language)** 이다.

### 6-2. 타입별 정리

| 자료형           | 설명                                 | 예시                                 |
| ------------- | ---------------------------------- | ---------------------------------- |
| **number**    | 숫자형 — 정수, 소수, `Infinity`, `NaN`  | `let a = 10;`                      |
| **bigint**    | 아주 큰 정수 (끝에 `n` 붙임)                | `let big = 1234567567890n;` |
| **string**    | 문자형 — `"`, `'`, `` ` `` 모두 가능      | ``let name = `Hi ${user}`;``       |
| **boolean**   | 참/거짓                               | `let isOpen = true;`               |
| **null**      | 의도적으로 “값 없음”                       | `let data = null;`                 |
| **undefined** | 값이 아직 없음 (자동 할당)                   | `let x;`                           |
| **object**    | 여러 데이터를 묶음 `{}`, `[]`              | `let user = {name:"jerry"};`       |
| **symbol**    | 고유 식별자 (잘 안 씀)                     | `let id = Symbol("id");`           |


### 6-3. type of 연산자
- **자료형을 확인할 때 사용하는 연산자이다.**
- 변수나 값 앞에 `typeof`를 붙이면 해당 데이터의 타입을 문자열로 반환한다.

```javascript
console.log(typeof "hello"); // string
console.log(typeof 123);     // number
console.log(typeof true);    // boolean
console.log(typeof null);    // object (JS 설계상의 버그이지만 표준)
console.log(typeof undefined); // undefined
```
