## **1. Figma MCP는 무엇인가?
- Figma MCP는 Figma 디자인 정보를 AI(예: ChatGPT, Cursor, Claude 등)가 직접 읽을 수 있게 연결해주는 브릿지역할을 한다.
즉 Figma의 실제 노드 / 컴포넌트 / 토큰 / 오토레이아웃 정보를 AI가 직접 컨텍스트로 읽고 코드·설명·리팩토링까지 해준다고 한다.
Figma에서 직접 디자인하지 않아도, 그냥 말 한마디로 화면을 만들어준다니 앱디자이너로써 좀 많이 당황하고 신기한 부분이라고 생각했다. (AI야 살려줘..)

## **2. AI로 만드는 디자인은 어떻게 작동할까?


## **2. 가능한 것들
- 디자이너 관점
- 컴포넌트 구조 자동 설명, 디자인 시스템을 문서 자동화함, 토큰 설명 요청

- 개발자 관점
- figma -> react / tailwind 코드 변환해주고 오토 레이아웃을 flex나 grid로 변환해준다. 그리고 디자인 변경사항을 diff 설명할수있고 컴포넌트 책임 분리를 제안할 수 있다.
