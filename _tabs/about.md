## 🎨 UX Portfolio
---

<a href="https://narae-ux-portfolio.vercel.app/" target="_blank" rel="noopener noreferrer">
포트폴리오 바로가기
</a>

포트폴리오 사이트는 단순 디자인 결과물이 아니라,  
실제 서비스를 어떻게 설계하고 구현했는지까지 함께 담아낸 프로젝트입니다.

### Tech Stack
- React
- TypeScript
- Tailwind CSS
- SCSS
- CVA(Class Variance Authority)

### What I Built
- UI/UX 디자인 및 프론트엔드 구현
- 컴포넌트 기반 디자인 시스템 구축
- 재사용 가능한 구조 중심 개발
- 팀 프로젝트 협업 경험
- PostHog 기반 사용자 데이터 분석
- AI 기반 개인 시스템 「나래봇」 구축

특히 “나래봇”은  
자연어 기반으로 제 경력과 프로젝트를 탐색할 수 있도록 만든 작은 AI 시스템입니다.

또한 GitHub 자동화와 연결하여  
업로드된 아티클을 매일 확인할 수 있는 구조로 구성했습니다.

현재는 RAG 기반 구조와 AI 기능 확장을 별도 프로젝트로 연구 중입니다.
